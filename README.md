## 🛠️ How to Run

Each solution can be executed using Python 3:

```bash
python dayXX.py
```

Replace `XX` with the day number. For example:

```bash
python day08.py
```

## 📥 Input Instructions

By default, scripts read input from:

```python
with open("input.txt") as f:
```

The input file should be located in the same directory as the script.

### Optional: Use Day-Specific Input Files

You don't need to rename all input files to `input.txt`. Instead, you can keep files named by day (e.g., `day08.txt`, `day12.txt`, etc.) and update the script accordingly:

```python
# Default
with open("input.txt") as f:
```

```python
# Day-specific input file
with open("day08.txt") as f:
```
